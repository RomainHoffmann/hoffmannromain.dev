Personal portfolio of Romain Hoffmann — Full-stack developer.

## Stack

- React + TypeScript
- Vite
- React Router
- CSS (vanilla)
- GSAP
- Lucide React

## Commands

```bash
npm install
npm run dev
npm run build
npm run preview
```
